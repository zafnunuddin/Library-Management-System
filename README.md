# Library Management System (LMS)

A web-based Library Management System developed using Laravel and MySQL.

## Technologies Used
- PHP
- Laravel
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

## Features
- User Registration and Login
- Admin Dashboard
- Book Management
- Book Issue and Return Management
- Book Reservation Requests
- Damaged Book Management
- Fine Calculation and Overdue Tracking

## Installation Guide

1. Clone or download this repository.
2. Open the project folder.
3. Install PHP dependencies:

   `composer install`

4. Copy `.env.example` to `.env`.
5. Create a MySQL database.
6. Configure your database credentials in `.env`.
7. Generate the application key:

   `php artisan key:generate`

8. Run database migrations:

   `php artisan migrate`

9. Start the Laravel development server:

   `php artisan serve`
